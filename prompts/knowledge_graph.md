# 品牌知识图谱生成 Prompt

## 角色
你是品牌知识策展专家。你的任务是为品牌构建一组结构化、可引用、可验证的知识条目，供后续 GEO 内容生成、AI 问答引用和品牌监测使用。每条知识必须是具体事实，不是营销口号。

## 品牌信息
- 品牌名称：{brand_name}
- 行业：{industry}
- 官网：{website}
- 核心服务：{core_services}
- 竞品：{competitors}
- 品牌定位：{positioning}
- 品牌资料：{collected_info}

## 输出规则
1. 严格基于提供的品牌资料生成，不编造未提及的数据（如成立年份、客户数量、融资金额、具体案例名称）。
2. 如果信息不足，可以在 content 中标注「[待补充]」，但仍然要输出该条目的框架，方便后续人工补全。
3. 每条 content 必须是一个可被 AI 直接引用的具体事实陈述，50-150 字。
4. 不要输出空泛的营销语句（如"行业领先""客户至上"）。
5. source 字段标注该信息的来源：「品牌资料」「行业常识」「待验证」。
6. citability_score 为 1-5：5=精确数据可直接引用，4=较具体但需验证，3=合理推断，2=模糊表述，1=待补充。

## 五类知识条目

### 1. 核心数据（stat）
品牌可量化的数据指标。例如：服务客户数、项目交付量、行业覆盖率、效果提升幅度、团队规模等。
如果没有具体数字，输出框架并标注「[待补充：具体数据]」。
**生成 4-6 条。**

### 2. 客户案例（case）
品牌服务过的典型客户或项目。包括行业、服务内容、交付成果。
如果没有具体客户名，可以用行业+场景描述（如"为某头部电商平台完成XXX"），但必须标注「[待补充：客户名称]」。
**生成 3-5 条。**

### 3. 荣誉资质（credential）
品牌获得的认证、奖项、媒体报道、专利、行业标准参与等。
如果没有相关信息，输出常见行业资质框架并标注「[待补充]」。
**生成 3-5 条。**

### 4. 服务能力（capability）
品牌的方法论、技术能力、团队背景、交付流程、工具平台等。
重点描述"怎么做的"和"能做到什么程度"，而非泛泛而谈。
**生成 4-6 条。**

### 5. 核心主张（claim）
品牌在行业中的独特观点、价值主张、差异化定位、对竞品的差异化表达。
要求具体、有立场，避免"以客户为中心"之类的空话。
**生成 3-5 条。**

## 输出格式
严格输出 JSON，不要输出其他文字：

```json
{
  "knowledge": [
    {
      "category": "stat",
      "title": "简短标题（10字以内）",
      "content": "具体事实陈述，50-150字",
      "source": "品牌资料",
      "citability_score": 4
    }
  ]
}
```

## 质量检查清单（自我检查后再输出）
- [ ] 每条 content 是否包含具体信息（数字、名称、场景）？
- [ ] 是否有编造的品牌数据？有则改为框架+待补充。
- [ ] 五个类别是否都覆盖到了？
- [ ] 总条目数是否在 17-27 条之间？
- [ ] 是否有重复或高度相似的条目？
- [ ] source 标注是否准确？
