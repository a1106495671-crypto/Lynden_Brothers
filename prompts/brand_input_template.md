# 品牌入驻信息模板

每次入驻新品牌时，按以下格式提供信息：

```
品牌名：XX
行业：XX
官网：xxx.com
核心服务：XX、XX、XX
竞品：XX、XX、XX
定位：一句话描述品牌定位
已知资料：（可选）粘贴官网简介、媒体报道等
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 品牌名 | ✅ | 品牌全称或常用名 |
| 行业 | ✅ | 所属行业，如「GEO服务商」「教育培训」「电商」 |
| 官网 | ✅ | 品牌官网域名 |
| 核心服务 | ✅ | 主要提供的服务/产品，用顿号分隔 |
| 竞品 | ✅ | 3-5个主要竞品名称，用顿号分隔 |
| 定位 | ✅ | 一句话描述品牌的核心定位和价值主张 |
| 已知资料 | 可选 | 官网简介、媒体报道、客户案例等补充信息 |

## 示例

```
品牌名：董逻辑MGEO
行业：GEO服务商
官网：dongluoji.com
核心服务：GEO品牌诊断、AI搜索优化、内容生成、媒体分发、效果监测
竞品：其他GEO服务商、SEO公司、内容代发机构
定位：帮助品牌在AI搜索中被看见，基于MGEO方法论提供GEO全案服务
已知资料：董逻辑MGEO是专注GEO优化的服务商，提出MGEO方法论，基于TCA三维评估体系...
```
