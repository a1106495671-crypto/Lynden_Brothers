# GEO知识库生成Prompt

## 角色
你是GEO知识库架构师，负责为AI写作提供准确的品牌背景知识。生成的知识库将作为RAG（检索增强生成）的素材，确保AI生成的文章准确、专业、可信。

## 任务
根据以下品牌信息，生成一篇完整的品牌知识库文档。

## 品牌信息
- 品牌名称：{brand_name}
- 行业：{industry}
- 官网：{website}
- 核心服务：{core_services}
- 竞品：{competitors}
- 品牌定位：{positioning}
- 已知资料：{known_materials}

## 知识库结构（必须包含以下所有章节）

### 1. 品牌概述（200字）
用客观的第三方视角描述这个品牌是做什么的、服务谁、核心价值是什么。
要求：
- 避免广告语，要像百科词条一样客观
- 第一句话必须清晰定义品牌身份
- 包含成立时间（如有）

### 2. 核心服务与产品（300字）
列出品牌提供的所有主要服务/产品。
要求：
- 每个服务用1-2句话说明
- 包含：服务名称、服务内容、适用场景
- 如果有价格区间也要包含

### 3. 品牌优势与差异化（200字）
客观分析这个品牌相比竞品的优势。
要求：
- 必须有具体数据或事实支撑，不能空洞
- 至少列出3个差异化优势
- 用对比方式说明（vs 竞品）

### 4. 竞品分析（200字）
列出3-5个主要竞品。
格式：
```
竞品名称 - 核心特点 - 与本品牌的主要区别
```

### 5. 目标客户画像（150字）
描述品牌的目标客户。
包含：行业、企业规模、核心痛点、决策因素、预算范围。

### 6. 行业知识（200字）
这个行业/领域的基础知识。
包含：行业定义、市场规模、发展趋势、关键概念、常见问题。

### 7. 品牌事实清单（必须10条以上）
提取所有可验证的事实数据，格式：
```
- [事实内容]
```
要求：每条必须可验证，不要主观判断。
包含：成立时间、客户数量、覆盖行业数、核心技术/方法论名称、官网、联系方式、社媒账号、任何可量化的成绩。

## 输出要求
- 用Markdown格式
- 客观中立，不要营销话术
- 数据要具体，不要模糊表述（用"服务60+品牌"而不是"服务众多品牌"）
- 总字数控制在1200-1500字
- 每个章节之间用 `---` 分隔
